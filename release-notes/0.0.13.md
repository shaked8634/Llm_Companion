# Release 0.0.13

**Release Date:** July 31, 2026

## New Features

- Favorite models from the model picker and keep favorites at the top of the list.
- Search models across names and providers in a flat, provider-labeled picker.
- Attach PDF files when using models and providers that support PDF input.
- Reuse the last response when continuing a conversation.

## Improvements

- Remove the empty "Select model..." option and automatically show the active model.
- Rebind prompt execution to `Ctrl+Shift+S` (`Command+Shift+S` on macOS).

## Fixes

- Avoid surfacing provider failures twice after they have already been handled.
