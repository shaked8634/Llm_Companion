# Release 0.0.14

**Release Date:** August 1, 2026

## New Features

- Show the generating model and elapsed response time with each assistant response.
- Give each browser tab its own LLM Companion side panel instance.
- Configure the streamed-response timeout from the new Advanced settings tab.

## Improvements

- Increase the default streamed-response timeout to 120 seconds.
- Keep long model and provider names from widening the model picker, while keeping all models reachable in the popup.
