# Release 0.0.17

**Release Date:** September 19, 2026

## Improvements

- Replace fixed Ollama and Custom rows with addable custom provider endpoints.
- Add stable provider IDs, editable names, validation, cleanup, and model discovery for custom endpoints.
- Support llama-swap root URLs through the OpenAI-compatible `/v1/chat/completions` endpoint.
- Show the failed custom-provider endpoint in connection errors.
- Preserve model search across popup and sidepanel openings for the current browser session.
- Show the extension version from `package.json` and remove the options-page module-preload warning.
